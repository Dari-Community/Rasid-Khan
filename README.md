# رسیدخوان | داری کامیونیتی

یک ابزار ساده برای حساب‌کردن خرید. کالاها را وارد کن، تعداد را تغییر بده و مجموع خرید و تخفیف را ببین.

## امکانات
- افزودن و حذف کالاها
- افزایش و کاهش تعداد
- محاسبه مجموع و تخفیف
- تخفیف درصدی (پیش‌فرض) یا مبلغی
- محدودیت تخفیف درصدی به ۱۰۰٪ و تخفیف مبلغی به مجموع خرید
- انتخاب واحد پول: افغانی (پیش‌فرض)، دالر یا تومان
- نگهداری فهرست در مرورگر
- طراحی راست‌چین و سازگار با موبایل

## اجرا
پوشه را باز کن و با Live Server اجرا کن.
